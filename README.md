# E-Commerce Customer Satisfaction & Retention Analysis

## Project Overview

This project focuses on analyzing customer satisfaction, delivery delays, seller performance, and repeat purchase behavior using an e-commerce dataset containing 97K+ orders.

The objective of this project is to identify operational and customer-related factors affecting customer retention and dissatisfaction using Python, SQL, Power BI, and DAX.

---

# Business Objectives

The project aims to answer key business questions such as:

* Does delivery delay increase customer dissatisfaction?
* Which product categories receive the highest bad reviews?
* Do delayed first-order experiences reduce repeat purchases?
* Which sellers generate the highest operational issues?
* Are bad reviews strongly associated with delayed deliveries?

# Key Insights

* Customer dissatisfaction increased sharply when delivery delays exceeded 3 days.
* Delayed first-order experiences negatively impacted repeat purchase behavior.
* Some product categories generated high bad reviews even without delivery delays, indicating product-quality related issues.
* High-volume sellers showed slightly higher operational issue rates.
* Overall repeat purchase rate was relatively low, indicating weak customer retention.
